# CSS Reset Playground

About the Project

This is a small project I am making while learning HTML and CSS. The main purpose of this project is to understand CSS resets and see how they effect the default styling of HTML elements in the browser.

I will create a sample HTML page with different elements like headings, paragraphs, lists, buttons, forms, images and tables. Then I will apply different CSS resets and compare how the page looks before and after applying them.

 What I want to learn

 Understand what CSS resets are and why we use them.
 See the difference between browser default styles and reset styles.
 Learn how different reset stylesheets works.
 Get more comfortable with HTML and CSS.

 Technologies Used

 HTML
 CSS
 JavaScript (for switching between different resets)

 Project Status

Currently working on it step by step as part of my learning process. More features and styling will be added as I continue learning.
